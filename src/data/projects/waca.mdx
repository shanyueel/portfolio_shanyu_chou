## Key Features & Contributions

### Data Warehouse

A centralized platform for managing and analyzing e-commerce data related to products, sales, and customer behavior. Built with Vue and TypeScript, providing a user-friendly interface for data visualization and reporting.

- **Data Visualization**: Engineered a dynamic data visualization dashboard, rendering complex business metrics into interactive charts and graphs, enabling users to intuitively analyze trends.
- **AI Recommendation**: Integrated ChatGPT's API to surface AI-driven business recommendations within the user interface to help users trust and act upon the data-driven suggestions.
- **Analytics & Comparisons**: Implemented an analytics toolkit, featuring customizable date-range pickers and dynamic metric comparison, that allow users to perform analysis of metrics such as sales trends, customer behavior, and more.
- **Library Selection**: Utilized _Echarts_ and _Vue3 Easy Data Table_ to build complex data visualizations and tables, significantly reducing development time while ensuring high performance and responsiveness.

### Core E-commerce SaaS Platform

A robust e-commerce platform that enables entrepreneurs to create and manage online stores with features such as product management, order processing, hold promotion activities, customer relationship management, and more.

- **Onboarding Page**: Guides new merchants through the essential initial setup of a complex e‑commerce platform, speeding time-to-first-configuration and reducing early support friction.
- **Rental Service**: Implemented a rental service feature that allows users to rent their products or spaces, expanding the platform's offering to attract a broader customer base.
- **UI Engineering**: Utilized Sass and BEM method to translate UI/UX designs from Figma into pixel-perfect, responsive web pages within a Laravel (Blade) environment.
- **Customer Support**: Diagnosed and resolved critical, customer-reported bugs in production environment, conducting analysis to implement robust, long-term solutions.

### Internal Management System

Centralizes configuration, merchant reporting, and announcement/promo publishing for different internal roles, streamlining daily operations and improving efficiency.

- **Project Modernization**: Migrated legacy PHP Laravel + jQuery codebase to Vue 3 & TypeScript, enhancing code maintainability, scalability, and developer productivity.
- **Interface Optimization**: Redesigned internal interfaces to improve usability and efficiency for various roles, including customer support, marketing, and operations teams.

## Technical Decisions

### Decision 1: Adopting Storybook for Design-Dev Bridging

- **Why**: UI inconsistencies between design and development teams causes delays and redundant rework.
- **Result**: Established a single source of truth for UI components, facilitating smoother collaboration with designers and other developers.

### Decision 2: Type-Safe Architecture with TypeScript

- **Why**: The complex data structures in the "Data Warehouse" required strict reliability to enhance maintainability.
- **Result**: Prevented runtime errors and clarified API contracts with both frontend and backend teams (via Postman integration).

### Decision 3: Pinia State Management

- **Why**: The application required a robust state management solution to handle complex data interactions and shared states across components.
- **Result**: Improved code organization and maintainability, ensuring a predictable and maintainable state for user permissions, search conditions and shared data across the application.

## Challenge: Team Allocation

- **Challenge**: The project timeline was tight, and with a small team of 2 frontend developers, it was challenging to allocate resources effectively to meet deadlines without compromising on quality.
- **Solution**: Listed all features before development began, breaking them down into manageable tasks. Assigned tasks based on the urgency and each developer's time, ensuring a balanced workload, and update and adjust the plan regularly with the project manager.
