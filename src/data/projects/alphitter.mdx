## Key Features & Contributions

### User Profiles:

- **Authentication**: Users can sign up for a new account or log in to an existing one.
- **User Profiles**: Each user has a profile page displaying their tweets, replies, and liked tweets.
- **Profile Editing**: Users can edit their personal information, including name, introduction, avatar, and background image.

### Tweeting System:

- **Timeline**: The main page displays a timeline of all users' tweets.
- **Tweeting & Engagement**: Users can create & post new tweets. They can also reply to and like tweets from other users.
- **Following System**: Users can follow and unfollow other users to customize their social network.

### Admin Management:

- **Independent Entry**: A separate login and web page for administrators to manage the platform.
- **Tweet Management**: Administrators can view all tweets posted by users and have the ability to delete any tweet.
- **User Management**: Administrators can view a list of all registered users on the platform.

## Technical Decisions

### Decision 1: Postman for API Documentation

- **Why**: With a tight delivery schedule, the frontend team couldn't wait for the backend team to complete API features before starting development.
- **Result**: Collaborated with backend engineers to create a shared API specification using Postman, allowing the frontend team to start development in parallel.

### Decision 2: Adopted Styled Components for Modular CSS-in-JS

- **Why**: Original CSS definitions were scattered across multiple files, leading to style duplication and maintenance challenges.
- **Result**: Adopted Styled Components to encapsulate styles within React components, promoting reusability and keep component structure, style, and logic together.

## Challenge: Remote Collaboration

- **Challenge**: Team members were in different locations with varying schedules, making frequent meetings difficult.
- **Solution**: Leveraged messaging apps and adopted Agile development practices, including online stand-ups and weekly sprint planning, to stay updated and ensure delivery on time.

## Outcome

- **~35% Code Reduction** by engineering ~18 reusable React components to standardize UI elements and minimize markup duplication.
- **3 Days Early Headstart**enabled by defining a shared Postman API specification, allowing parallel frontend-backend development and decoupling dependencies.
